# Interface Contract: Internationalization (i18n)

**Location**: `messages/es.json`, `src/i18n/request.ts`  
**Purpose**: Centralize user-facing text strings in Spanish, decouple content from markup, and provide compile-time type-safety for translation keys.

---

---

## 2. Request Configuration Contract (`src/i18n/request.ts`)

- Uses `getRequestConfig` from `next-intl/server`.
- Default locale: `'es'`.
- Dynamic import of `../../messages/es.json`.

---

## 3. Type Augmentation Contract (`src/types/global.d.ts`)

```typescript
import es from '../../messages/es.json';

declare module 'next-intl' {
  interface AppConfig {
    Messages: typeof es;
  }
}
```

---

## 4. Component Usage Contract

- **Server Components**:
  ```typescript
  import { getTranslations } from 'next-intl/server';
  const t = await getTranslations('Pqrsdf');
  return <h1>{t('title')}</h1>;
  ```
- **Client Components**:
  ```typescript
  'use client';
  import { useTranslations } from 'next-intl';
  const t = useTranslations('Common');
  return <span>{t('loading')}</span>;
  ```
